# MangaKatana

Native Vestra SDK 1.6 manga port of Seanime Providers' `src/manga/mangakatana/provider.js`, reviewed at commit `60f46c873d20efcb977eaf8a010672fe526db229`. MIT; see the repository's third-party notices.

Search follows source pagination rather than truncating a page. Chapter lists exclude related-series links and preserve decimal chapter numbers. Reader arrays are parsed as string data, without executing remote JavaScript. Only reviewed source/CDN hosts are allowed; images carry the source referer.
