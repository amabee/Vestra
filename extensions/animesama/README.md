# AnimeSama (French Manga)

Native SDK 1.6 port of `src/manga/animesama/provider.js` at Seanime Providers commit `60f46c873d20efcb977eaf8a010672fe526db229`. MIT; see third-party notices. Only catalogue cards with scans are returned. Exact oeuvre spacing is preserved for the chapter-count API. Separate scan panels keep distinct IDs, and page counts are refreshed instead of embedded into saved chapter identities. The upstream live-search endpoint does not advertise extra search pages.
