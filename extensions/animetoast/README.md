# AnimeToast

Native source adapted from Seanime Providers (MIT), Copyright (c) 2025 Pal. See anime-ports.json, THIRD_PARTY_NOTICES.md and licenses/seanime-providers-MIT.txt. Retains Ger Sub/Dub title variants, follows labelled episode links without positional guesses, and extracts literal MP4 data. Current reviewed titles expose other mirrors instead of MP4Upload, so playback is unverified. Unsupported embeds are reported explicitly and never returned as video files.
