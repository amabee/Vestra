# FanFox

Native SDK 1.6 port of Seanime Providers' `src/manga/fanfox/provider.js` at commit `60f46c873d20efcb977eaf8a010672fe526db229`. MIT; see third-party notices. Uses source-owned search and chapter regions and extracts only reader images. Chapter IDs are restricted to the chosen series; other origins, traversal and unknown image hosts are rejected. Live availability is recorded separately in the catalogue.
