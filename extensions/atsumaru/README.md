# Atsumaru

Native SDK 1.6 adaptation of Seanime Providers' `src/manga/atsumaru/provider.js` at commit `60f46c873d20efcb977eaf8a010672fe526db229`. MIT; see third-party notices. Uses real Typesense pagination, stable book/chapter IDs, ordered page numbers and exact CDN grants. Alternative chapter editions retain distinct IDs rather than being discarded because their numbers match.
