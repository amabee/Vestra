# MangaBats (Manganato)

Native SDK 1.6 port of `src/manga/manganato/provider.js` at Seanime Providers commit `60f46c873d20efcb977eaf8a010672fe526db229`. MIT; see third-party notices. The current upstream backend is MangaBats. Chapters are fetched in bounded source pages; partial failures and repeated pages are errors rather than silently truncated inventories. Reader string arrays are parsed without evaluating JavaScript.
