# AnimeGG

Native Vestra anime source adapted from Seanime Providers (MIT), Copyright (c) 2025 Pal. Reviewed upstream file and revision are in anime-ports.json. See THIRD_PARTY_NOTICES.md and licenses/seanime-providers-MIT.txt.

Uses native search/getEpisodes/getStreams methods, separate GG-SUB and GG-DUB mirrors, all advertised qualities, and literal data parsing without remote script evaluation. Exact network grants cover metadata and player extraction. Media URLs still pass Nova’s guarded playback transport.
