Native source adapted from Seanime Providers (MIT), Copyright (c) 2025 Pal. See anime-ports.json, THIRD_PARTY_NOTICES.md and licenses/seanime-providers-MIT.txt. The network:session permission sends only the public episode selector key to animeheaven.me/gate.php; it does not read browser cookies or account data. Parser ignores commented-out players and never fabricates a stream from unrelated tokens.
