# Read manga

Select a provider in Manga Library before searching or opening a title. The same
selection carries into Manga Details and the reader.

## Open chapters

Open a title's details to see its cover, information and available chapters. Vestra
matches the selected source and retrieves chapters automatically. Sources can have
different editions, translations and chapter numbering.

## Choose a reading layout

Use single-page or double-page layouts for paged manga, continuous scrolling for
long strips, or webtoon mode for vertical chapters. Adjust reading direction and
page fitting for the series instead of assuming every source uses the same format.

## Read without controls

Click the page to hide reader controls; click again to show them. Settings include
immersive and fullscreen controls. The progress bar supports navigation and hover
previews where page images are available.

## Resume later

Reading progress belongs to Vestra. Extensions return chapters and image metadata;
they do not need a progress database. Keep the same installed source ID to retain
the relationship between saved progress and chapters.

## Author a source

The [native manga contract](../native-manga-sdk.md) covers chapter IDs, image hosts
and page indexes. Image downloads stay in the host's guarded pipeline instead of
passing image bytes through extension JavaScript.
